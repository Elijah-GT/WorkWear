# WorkWear
Wearable for construction workers to prevent and aid in workplace injuries.

Hackathon MVP: a helmet-mounted sensor that detects falls and measures heat exposure, reporting to a supervisor dashboard.

- [`CLAUDE.md`](CLAUDE.md): what we're building, decisions, hardware and safety rules

- [`docs/PROTOCOL.md`](docs/PROTOCOL.md): every message between helmet, server, and dashboard
- [`server/README.md`](server/README.md): run the server and the fake-helmet simulator
- [`dashboard/README.md`](dashboard/README.md): open and use the supervisor dashboard
